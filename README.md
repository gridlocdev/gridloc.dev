# gridlocdev's portfolio

This repository contains my portfolio website, where I display website links to my developed projects as well as some
other stuff. <https://gridloc.dev/>

## How it works

It's plain HTML and CSS in `site/`. There is no JavaScript, no dependencies and no build step, and the page
works in any browser.

To preview it locally, run any static file server, for example:

```sh
python3 -m http.server -d site 8080
```

To add a project, see the comment at the top of `site/index.html`.
